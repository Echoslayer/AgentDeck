# 門檻與共識

**實作前必讀：[組合與改寫說明](IMPLEMENTATION.md)**。重用「對齊數值 → 門檻判定 → 多來源投票 → 共識」的表示方式。

## 用途

適合比較多個來源對同一組位置／項目的入選判斷。可用於量測、評估或區域比較；前提是欄位可對齊，且共用門檻有明確語意。

## 試玩

雙擊 [index.html](index.html)。初始門檻 0.5、三來源過半數，位置一、二、五通過。改「全部同意」只剩位置一；取消所有來源時不定義共識。

## 組成

- `demo.js`：六個位置、三個人工來源、輸入表格與投票圖。
- `compute.js`：`consensus(series, selected, threshold, rule)`，回傳票數、最低票數與通過狀態。
- `../demo.css`：展示外殼，改寫時取用需要的部分。

更換欄位與來源資料即可套用其他主題；資料對齊與門檻語意見追加說明。
