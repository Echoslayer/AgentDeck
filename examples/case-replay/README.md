# 同案例結果回放

**實作前必讀：[資料與改寫方式](IMPLEMENTATION.md)**。重用的是「選案例與結果 → 同步更新參照、數值與來源」的表示方式，不是穩定元件 API。

## 用途

適合已保存的實驗結果、同樣本不同方法、同案例不同模型版本比較。只有顯示層切換時，不應宣稱即時重跑模型；沒有相同案例與量測條件的資料，不適合直接並排比較。

## 試玩

雙擊 [index.html](index.html)。起始案例 A、設定 A，示意耗時為 100 → 75 ms，差 −25 ms。切到案例 B、保持設定 A，兩側同時變成 B 的紀錄：80 → 90 ms，差 +10 ms。切回 A 後不應殘留 B 的數值或來源 ID。

人工資料刻意讓同一設定在不同案例有不同方向的變化。這只是回放與對齊的檢查，不是工程效益實驗。

## 組成

- `compute.js`：驗證案例／結果 ID、對齊位置與量測值，選取同案例基線及結果，計算耗時差。
- `demo.js`：兩個人工案例、各三個結果，以及同步畫面更新。
- `../demo.css`：既有示範外殼；改寫到主題時取用必要樣式並加主題前綴。

主題需持有自己的資料、來源與更新程式。固定作者說明可編輯；案例結果由資料重新產生，不標記 `data-edit`。
