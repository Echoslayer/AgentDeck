# 連動与驗收

- `evolution` 管圖、階段、進度與靜態預覽；主題管需求、前後結果與揭曉狀態。不要把課程領域欄位放進元件 API。
- 每階只引入一個可以回答具體問題的能力；結果必須對應同一案例。假數值、查表回放與真實計算需清楚區分。
- 元件發出 `deck:evolution` 事件，`detail.step` 為 0 起算。在正式頁面的 `mount` 中先註冊事件；核心在 mount 之後啟動元件並送出初始階段；回傳函式移除監聽器。使用 `state` 保存主題自己的版本／揭曉狀態。
- 固定可編輯說明放在結果容器外；切換只更新結果容器。互動頁提供 `previewArt`，放完整演進圖與前後結果摘要。
- 驗收：選階段後重設預測；同階切版本能比較兩個結果；換頁返回保持階段；圖片匯出不依賴正在操作的 DOM。
