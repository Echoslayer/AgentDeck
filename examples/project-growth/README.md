# project-growth：需求推動專案演進

## 用途
讓讀者理解「前一版卡在哪裡，因此新增什麼能力」。以同一筆待辦的輸入、空白檢查、跨重啟保存為例，組合正式 `evolution` 元件與主題自有的前後結果回放。

## 操作與限制
選一階段，讀需求、預測前一版的結果，按揭曉，再切到本課版比較。只回放人工預期結果，不執行資料庫、不證明實際系統正確。

## 改寫與驗收
改寫 `demo.js` 的節點／階段與 `compute.js` 的需求及前後結果；每個差異都要有教材或實測依據。正式主題以 `agentdeck add evolution` 取得元件，自行持有案例資料；不可引用 examples。

實作前必讀：[連動與驗收](IMPLEMENTATION.md)。

檢查：`node examples/project-growth/check.cjs`；瀏覽器另驗三階切換、預測揭曉、前後結果、窄版與靜態後備。
