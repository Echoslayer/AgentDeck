# 解析度比較

**實作前必讀：[組合與改寫說明](IMPLEMENTATION.md)**。本範例重用的是「固定參照 → 改變聚合尺度 → 比較細節」的表示方式；不是正式元件 API。

## 用途

適合空間矩陣、量測網格或影像顯著值的尺度比較；不適合用來推論下採樣後模型的準確率。

## 試玩

雙擊 [index.html](index.html)。選局部尖峰，將右側從 6 降為 1：原始最大值為 10，聚合後單格為 26/36。換成交錯分布並選 3：所有區塊平均為 5。

## 組成

- `demo.js`：小型人工資料、控制項與兩張數值熱圖。
- `compute.js`：`aggregate(matrix, rows, cols)`，只負責平均。
- `../demo.css`：示範外殼，改寫到主題時只取需要的樣式並加主題前綴。

資料不依賴特定領域；依追加說明更換矩陣、尺度與標籤即可改寫。
