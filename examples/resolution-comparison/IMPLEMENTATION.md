# 解析度比較：實作追加說明

## 關係與資料

表示的是同一份資料在不同觀察尺度下的差異。輸入為非空、矩形、有限數字的二維矩陣；輸出尺寸為正整數，不大於輸入。示範是 6×6、值域 0–10 的人工資料，這些常數不屬於計算函式的限制。

## 狀態與更新

固定資料 → 選擇資料與輸出尺寸 → 區塊平均 → 更新右圖與摘要。左图保持同一份原始矩陣，左右色階固定且一致。`compute.js` 沒有 DOM 或主題依賴；`demo.js` 承接選單事件與畫面。

聚合區塊的邊界是 `floor(index * sourceSize / targetSize)`。不能整除時，區塊面積可能不同；每格仍為自身區塊平均，不能再把輸出各格等權平均宣稱等於原圖平均。需要總量守恆時，應改用加總或帶面積的加權運算並更新說明。

## 改寫到主題

1. 換掉 `demo.js` 的 datasets、控制選項與文字；保留來源、單位、範圍與聚合語意。
2. 色階依完整原始資料決定，正負值需另設有零點的色階；不能直接把本例 0–10 色彩公式用在任意值域。
3. 若加入圖片疊圖，明確定義矩陣和圖片的座標對應；透明度只改顯示，不代表重算來源。
4. 嵌入 reader 時，將 DOM 查詢限縮到元件 root，事件移入頁面 mount，回傳清理函式；用 state 保存資料 ID 與尺寸。另提供無控制項的 previewArt。
5. 程式與資料放到主題目錄；不要直接引用 examples。

## 驗收與限制

- 等尺寸輸出應完全等於輸入；常數矩陣在任何合法尺寸仍為常數。
- 交錯矩陣聚合到 3×3 應全部為 5，1×1 應等於全圖平均。
- 檢查兩圖色階一致、數值可讀、窄版面不裁切，以及換頁返回的狀態。
- 此操作改變資訊摘要；不能聲稱已重新推論、重新測量或提升結果可信度。
