# 局部干預回放

**實作前必讀：[資料格式與改寫方式](IMPLEMENTATION.md)**。重用的是「選一部分輸入替換 → 對照前後輸出 → 排序各部分影響」的表示方式，不是穩定元件 API。

## 用途

適合消融實驗、敏感度分析、區域遮擋、移除某個欄位或模組後看結果變化：輸入能切成固定的幾塊，每塊各有一次已保存的替換結果。不適合多塊同時替換的交互作用，也不適合沒有逐塊紀錄、只能事後估算的情況。

## 試玩

雙擊 [index.html](index.html)。起始為案例 A、替換區塊 5：追蹤輸出「甲」55 → 28（−27），最高輸出改為「乙」。點區塊 7 是唯一的值 0：顯示「未測」，因為輸入已等於替換值。切到案例 B，追蹤輸出改為「乙」；區塊 5 讓它上升 +4，表示替換也可能讓分數變高。

## 組成

- `compute.js`：驗證輸入、替換值與逐塊紀錄，選取一次替換，算追蹤輸出的變化、最高輸出是否改變與全部區塊的排序。
- `demo.js`：兩個人工案例、3 × 3 輸入，以及同步畫面更新。
- `../demo.css`：既有示範外殼；改寫到主題時取用必要樣式並加主題前綴。

主題需持有自己的資料、來源與更新程式。固定作者說明可編輯；替換結果由資料重新產生，不標記 `data-edit`。
