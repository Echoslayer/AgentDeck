# 加權評分

**實作前必讀：[組合與改寫說明](IMPLEMENTATION.md)**。重用「固定分項表格 → 權重 → 貢獻分解 → 排名」的表示方式。

## 用途

適合探索評分偏好與排序的關係。分項需有可比較的尺度與方向；原始延遲、金額或比例不能未轉換就混算。

## 試玩

雙擊 [index.html](index.html)。三方案的人工資料各有所長：等權重 C 第一，只看速度 A 第一，只看可靠度 B 第一。把權重全設為 0，總分應顯示未定義。

## 組成

- `demo.js`：項目、評分欄位、色彩與起始權重；固定表格與動態堆疊長條。
- `compute.js`：`rank(items, weights, max)`，回傳正規化權重與排序後的各項貢獻、總分。
- `../demo.css`：展示外殼，改寫時取用需要的部分。

若一個項目的所有分項都不低於另一項，非負權重無法翻轉兩者順序；詳見追加說明。
