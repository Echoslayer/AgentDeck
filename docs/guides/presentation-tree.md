# 簡報樹星圖與搜尋（閱讀器內建的跨分支導覽）

一組簡報要讓讀者從總覽選章、隨時跳到另一講時，可以做成一棵簡報樹。根目錄的 `index.html` 是主幹，每講用 `agentdeck new <名稱> --related branches` 建立分支。

在主幹與所有分支的 `story.sequence` 引用同一份清單。第一筆填主幹，後面照閱讀順序列出各講。每筆填入口連結 `href` 和顯示名稱 `label`；課程已有主題分組時，再填 `group`。可直接沿用課程地圖的資料。共用腳本與相對路徑的範例見單位內的 `agentdeck/AGENTDECK.md`「簡報樹」。

開啟任一分支，翻頁列的「投影片總覽」旁會出現「簡報樹」。點星圖節點可跳講，也能輸入編號、名稱或分組搜尋。這是閱讀器內建導覽，會和跨章翻頁一起沿用清單。既有簡報樹若只有手寫目錄，先用 `agentdeck update core` 更新閱讀器，再將目錄整理成共用清單。
