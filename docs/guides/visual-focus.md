# 視覺焦點與版面引導寫作指引（建議）

每一頁都適用。排版的工作是決定觀眾第一眼看哪裡、接著往哪裡看，而不是把東西放整齊。研究依據與實例見上游 `docs/studies/page-focus-study-20261124.md`。

## 原則

1. **一頁一個焦點**：觀眾此刻該看的那個東西。其他元素要嘛帶視線走到焦點，要嘛退到背景。
2. **焦點靠圖內強調，不靠框**：顏色、粗細、大小、對比決定第一眼。把要看的那一列、那個節點、那段曲線標出來；能直接標在圖上的就不要另寫圖例。
3. **框是分組，不是強調**：同一個框裡的東西會被看成一組，而且這個效果強過靠近或同色。只框真正要一起讀的內容；不要為了「顯得重要」加框，也不要在 `.stage` 裡再套一層帶外框的面板。
4. **讀圖的話貼著圖**：會讓讀者回頭看圖的句子，要放在它指向的東西旁邊，不要和圖隔著框線。
5. **標題是入口，附註退後**：大標題最大、最上面，天生先被讀到，放在框外沒有問題；寫成這頁要說清楚的一句話。來源、限制、延伸連結放 `detail`，在框外、低對比。
6. **焦點先由內容決定**：版面救不了沒有焦點的頁面。視線引導做不好時，先查內容，再調版面；字多通常是焦點不清的結果，不是原因。

## 先修內容

- **標題只指向一個焦點**：「A、B 和 C 各做什麼？」會讓讀者把每一項都讀一遍；寫成這頁的結論（「追一片晶圓判完沒，只看 1001」）。改寫後回頭核對事實，結論句比問句更容易寫錯。
- **只留講到的東西**：表格的列、圖的節點、清單的項目，講稿沒提到、也不是對照所需的就拿掉；其餘事實一句帶過放進 `detail`，或移到講那件事的頁面。
- **同色就是同一級**：一頁只留一種強調色給焦點。其他地方用了同一個顏色，讀者會以為它們一樣重要；整份簡報固定用法的標記（例如問題標記）保留，但不要再在同頁加第二個強調。
- **`lead` 可以省略**：它只是重複標題時就刪掉。閱讀器為 `lead` 保留最小高度，留空會出現一段空白，可在主題的 `story.css` 加 `#page .lead:empty{display:none}`。
- **`detail` 只放同一件事的附註**：另一個主題的事實不要接在焦點後面，讓讀者剛看懂就得理解新東西。

## 每頁怎麼排

| 內容 | 放哪裡 |
| --- | --- |
| 章節、`title` | 框外，作為入口 |
| `lead` | 框外；它若是在教讀者怎麼看這張圖，改寫成圖內標註 |
| `art` | 框內；焦點用圖內強調標出 |
| 讀圖的話（指向圖中某處的句子） | 貼著它指向的東西：直接標在圖上，或寫成緊鄰圖的圖說，放進 `art` |
| `point` | 整頁要帶走的理解；它若只是在說「看圖中的某處」，那句話屬於上一列 |
| `detail` | 框外，低對比 |

判斷一句話放哪裡，只問一個問題：**這句話會不會讓讀者回頭看圖？** 會就貼著圖，不會就留在框外。

## 檢查

- **3 秒瞥視**：截圖後只看 3 秒再移開，說得出這頁的重點、記得第一眼落在哪裡，焦點才算成立。
- **路徑**：從標題開始，視線是否依序經過焦點、讀圖的話，最後才到附註；中間有沒有被框線、另一個強調色或裝飾攔下。
- **一個焦點**：同一頁只有一處最強的對比；第二個強調色出現時，先問它是不是在搶焦點。
- 有講者動作（`record` 的 `box`、`arrow`）時，標註指向的就是當下的焦點，要和畫面上的強調一致。
