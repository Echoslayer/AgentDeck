# 0022. 口語稿與朗讀：選填 speech 與 audio，有音檔播音檔，否則以瀏覽器內建語音念出，可全部播放、調語速、開字幕

- 狀態：已接受
- 日期：2026-10-02

## 背景

講者想讓簡報把講稿念出來，用於排練、錄音或無人講解的播放。瀏覽器內建的「大聲朗讀」（Edge）或閱讀模式只能念整頁 DOM，會連畫面文字、導覽列一起念，也無法只挑講稿中要說出口的句子。`instruction`（[0020](0020-instructions-and-comments.md)）混合了動作提示（「指左邊」「停兩秒」）與台詞，直接朗讀會把提示也念出來；從「」抽取台詞也不可靠，因為按鈕名稱、標籤同樣用「」。

## 決策

1. **新增選填欄位 `speech`（口語稿）**：頁面資料的字串（HTML，可用 `<b>`、`<br>`），只寫講者實際說出口的話，不含動作提示。`deck.cover()`、`deck.end()` 也接受。人要求逐字稿或朗讀時才寫；`instruction` 照舊每頁都寫。
2. **選填欄位 `audio`（口語稿音檔）**：路徑字串，檔案放在簡報資料夾的 `audio/`，以 `resource()` 引用，用瀏覽器內建的 `Audio` 播放。有音檔就播音檔；沒有音檔、或音檔載入失敗時，退回第 5 點的內建語音念 `speech`。右側「講稿」分頁與簡報者視窗的口語稿旁有「▶ 播放」或「▶ 朗讀」按鈕，R 鍵切換；換頁、關閉頁面即停止，只處理目前這頁。
3. **全部播放與語速**：頁首、講稿分頁與簡報者視窗有「⏵ 全部播放」（P 鍵），從目前這頁開始逐頁發聲，念完自動翻到下一頁，沒有口語稿的頁停留 2 秒，到最後一頁結束；播放中手動換頁就從新頁接著念。本決策只念口語稿、不操作畫面；要畫面跟著念的內容動，見 [0024](0024-speech-synced-actions.md)。語速按鈕在 0.75×、1×、1.25×、1.5×、2× 間切換，同時套用到音檔與內建語音，存在講者本機。
4. **字幕**：同樣三處有 CC 按鈕（S 鍵），開啟後朗讀時在投影畫面下方以半透明底顯示目前這句，念完或停止即隱藏，不擋點擊。句子取自 `speech`；內建語音逐句同步，音檔有 `cues`（[0024](0024-speech-synced-actions.md)）時照秒數，沒有時依播放進度按句子字數比例估算。只有音檔、沒有 `speech` 的頁不顯示字幕。開關存在講者本機，預設關閉。
5. **內建語音用 Web Speech API 的 `speechSynthesis`**：瀏覽器內建，不新增套件。
6. 語音依 `<html lang>` 挑選（`zh-Hant` 優先 `zh-TW`），同語言有 Natural 語音時優先。文字逐句念出，避免部分瀏覽器截斷長段落，改語速也能從下一句生效。
7. `agentdeck export` 把口語稿以【口語稿】寫進 pptx 備忘稿；有音檔時嵌入投影片右下角，放映時點擊播放。
8. 實作在 `deck-editor.js`，相容新增，契約版本不遞增。

## 理由

- 獨立欄位讓「念什麼」由作者明確決定，不靠解析 `instruction` 猜測；兩者讀者不同：動作給講者看，口語稿給講者念或給機器朗讀。
- 人錄的音或預先產生的高品質語音比即時合成自然，但不是每份簡報都有；以音檔為主、內建語音為退路，作者不必為每頁準備音檔也能朗讀。
- `speechSynthesis` 與 `Audio` 在 Edge、Chrome、Safari、Firefox 都可用，零依賴符合離線打包交付（[0011](0011-vendor-manifest-and-packing.md)）。

## 後果

- 語音品質與可用語言取決於瀏覽器與作業系統；Edge 的 Natural 語音需要網路，離線時退回系統語音。沒有對應語言的語音時，瀏覽器以預設語音念出。
- 不支援 `speechSynthesis` 的環境不顯示朗讀按鈕，口語稿仍可閱讀。
- 音檔隨簡報單位一起打包，會增加打包大小。`speech` 與音檔內容不同步時框架無法察覺，由作者維護。
- 全部播放本身只翻頁；要自動操作互動或標註，改在 `record` 加 `at`（[0024](0024-speech-synced-actions.md)）。
- 音檔的字幕是估算，語速不均或停頓長的錄音會與聲音錯開一兩句；需要精準時把 `speech` 斷句寫得更短。字幕只顯示在主視窗，`agentdeck export` 不輸出字幕。
