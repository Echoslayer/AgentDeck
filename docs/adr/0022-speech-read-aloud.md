# 0022. 口語稿與朗讀：選填 speech 欄位，以瀏覽器內建語音念出

- 狀態：已接受
- 日期：2026-10-02

## 背景

講者想讓簡報把講稿念出來，用於排練、錄音或無人講解的播放。瀏覽器內建的「大聲朗讀」（Edge）或閱讀模式只能念整頁 DOM，會連畫面文字、導覽列一起念，也無法只挑講稿中要說出口的句子。`instruction`（[0020](0020-instructions-and-comments.md)）混合了動作提示（「指左邊」「停兩秒」）與台詞，直接朗讀會把提示也念出來；從「」抽取台詞也不可靠，因為按鈕名稱、標籤同樣用「」。

## 決策

1. **新增選填欄位 `speech`（口語稿）**：頁面資料的字串（HTML，可用 `<b>`、`<br>`），只寫講者實際說出口的話，不含動作提示。`deck.cover()`、`deck.end()` 也接受。人要求逐字稿或朗讀時才寫；`instruction` 照舊每頁都寫。
2. **朗讀用 Web Speech API 的 `speechSynthesis`**：瀏覽器內建，不新增套件、不呼叫外部服務。右側「講稿」分頁與簡報者視窗的口語稿旁有「▶ 朗讀」按鈕，R 鍵切換；換頁、關閉頁面即停止，只念目前這頁。
3. 語音依 `<html lang>` 挑選（`zh-Hant` 優先 `zh-TW`），同語言有 Natural 語音時優先。文字逐句排入佇列，避免部分瀏覽器截斷長段落。
4. `agentdeck export` 把口語稿以【口語稿】寫進 pptx 備忘稿。
5. 實作在 `deck-editor.js`，相容新增，契約版本不遞增。

## 理由

- 獨立欄位讓「念什麼」由作者明確決定，不靠解析 `instruction` 猜測；兩者讀者不同：動作給講者看，口語稿給講者念或給機器朗讀。
- `speechSynthesis` 在 Edge、Chrome、Safari、Firefox 都可用，零依賴符合離線打包交付（[0011](0011-vendor-manifest-and-packing.md)）。

## 後果

- 語音品質與可用語言取決於瀏覽器與作業系統；Edge 的 Natural 語音需要網路，離線時退回系統語音。沒有對應語言的語音時，瀏覽器以預設語音念出。
- 不支援 `speechSynthesis` 的環境不顯示朗讀按鈕，口語稿仍可閱讀。
- 不提供念完自動翻頁；需要無人播放時再另行決定。
