# 0029：將逐階演進圖與教學結果回放分開

## 狀態
已接受，2026-10-03。

## 背景
Siguard 課程用階段揭露專案如何形成。主題內手寫 SVG 的文字、節點與連線依賴固定座標，內容增加後需要反覆調整間距。理解上的價值來自「前一版的缺口促成新增能力」，與配色或動畫無關。

## 決策
1. 新增特殊元件 `evolution`，零套件依賴。作者提供節點、連線與階段，元件管理有向無環圖分層、階段操作、進度保存與静態後備。不接受主題座標，也不擴充成通用圖編輯器。
2. 節點使用可換行 HTML；連線依實際外框計算，ResizeObserver 處理字體、容器與編輯後尺寸。窄容器改成直向；換階段保留節點位置。
3. 靜態後備保留完整節點、文字形式的連接來源與所有階段原因。互動由既有 live 生命週期啟動與清理，縮圖和分享匯出不依賴操作中的 DOM。
4. 前後版本的需求、預測與結果由主題維護。`project-growth` 範例示範通过 `deck:evolution` 事件連動，元件不接收 Siguard 特有資料。Siguard 改用正式元件，作為下游驗證。
5. 本次不把課程的獨立捲動樣式搬進核心。使用者後來確認的遮擋在圖內；閱讀器已為固定導覽列保留底部空間。更換全站捲動容器會涉及註記、編輯與焦點，需要獨立需求與驗證。
6. 新增相容元件，不改 CONTRACT；不新增套件，不改品牌主題。

## 後果
作者不再維護像素座標；長文字、分支連接、窄版、狀態保留、人工修改與清理都有瀏覽器檢查。適用小型、單一關係的演進圖；循環、刪除節點與替換架構仍需主題另行表達。教學範例保留改寫彈性，元件只負責圖與階段。
