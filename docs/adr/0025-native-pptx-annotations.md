# 0025. 匯出 pptx：只有標註的 record 改為原生圖形與出現動畫

- 狀態：已接受
- 日期：2026-10-02

## 背景

[0024](0024-speech-synced-actions.md) 決定 6 讓匯出照順序執行所有 `record` 步驟並錄影，標註（`arrow`、`box`、`clear`）也一起錄進 mp4。很多頁的講者動作只是依序框出重點，沒有操作元件。錄成影片後，PPT 裡的紅框無法編輯或刪除，講者也不能照自己的節奏按一下出現下一個，影片還會讓檔案變大。PowerPoint 本身就有矩形、箭頭和「出現」動畫，足以表達「依序框出」。

## 決策

1. **判定**：`record` 只含 `box`、`arrow`、`clear`、`wait`（可帶 `at`、`text`、`from`），且至少有一個 `box` 或 `arrow` 時，這頁不錄影。含 `click`、`set`、`drag` 的頁照 [0021](0021-pptx-export.md) 錄影，不拆成半截圖半影片。
2. **畫法**：內容區放截圖，標註畫成 PPT 原生圖形疊在截圖上。紅框是圓角矩形外框，箭頭是帶三角箭頭的線，`text` 是紅底白字的圓角標籤。位置在瀏覽器量出目標相對 `.stage` 的範圍後換算，間距、箭頭長度、線寬、字級與 `deck-editor.js` 的畫法相同，顏色固定為 `#E5484D`。
3. **動畫只用「出現」與「消失」**，不用淡入、飛入或路徑：
   - 有 `at` 時，每個帶 `at` 的步驟開始新的一下，其後沒有 `at` 的步驟併入同一下（同 0024 的分組）。
   - 沒有 `at` 時，每個 `box`／`arrow` 各一下。
   - `clear` 讓目前的標註消失：有 `at` 時在該下發生；沒有 `at` 時併入下一下，在新標註出現時同時消失；最後一步是 `clear` 時自成一下。
   - 同一下裡的 `wait` 換成「接續前一項」的延遲，保留「框一下、停一下、再換」的節奏。
4. pptxgenjs 不支援動畫，匯出寫出 pptx 後在對應投影片的 XML 補上 `<p:timing>`。標註圖形以 `agentdeck-mark-<n>` 命名，並改用不與其他物件衝突的 id。沒有標註頁時不做後處理。
5. 不需要 ffmpeg；沒有 ffmpeg 的環境，只有標註的頁也保留動畫。
6. 實作在 `cli/lib/export.mjs`，沿用既有的 `cli/lib/zip.mjs`，不新增套件；頁面資料格式不變，契約版本不遞增。

## 理由

- 只有標註的頁本質上是「靜態畫面加依序強調」，正好對應 PPT 的形狀與動畫。講者可以照自己的節奏按，也能在 PowerPoint 裡移動、改字或刪除標註。
- 「出現」是最簡單、各版本 PowerPoint 都支援的動畫，也和 HTML 版的標註語意相同，不另外發明效果。
- 同一份 `record` 繼續給播放與匯出共用，作者不必為 PPT 另寫一套。

## 後果

- 取代 0024 決定 6 裡「標註也錄影」的部分；含元件操作的頁仍照 0024 錄影，忽略 `at`。
- 截圖是載入時的畫面。只有標註的 `record` 不改變元件狀態，所以截圖與 HTML 版看到的畫面相同。
- 換算以截圖縮放比例為準。PPT 字型與瀏覽器不同，標籤寬度可能略有差異，標籤不換行。
- 標註可以落在 `.stage` 外（例如標籤在框上方），PPT 會照樣畫出；仍建議讓標註落在 `.stage` 內，與錄影頁一致。
- 在 PowerPoint 編輯畫面，所有標註同時顯示；放映時才依序出現。
