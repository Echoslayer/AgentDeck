# 0028. 瀏覽器端以靜態圖片匯出 PDF 與 PPTX

- 狀態：已接受
- 日期：2026-10-03

## 背景

臨時分享需要讓讀者直接從頁面下載檔案，不必要求 LLM 或準備 CLI 錄影環境。圖片足以保留內容，不需要可編輯文字、互動錄影或動畫。

## 決策

1. 頁首提供「匯出」對話框，下載整份 PDF 或 PPTX；每頁是一張圖片，統一 16:9，較長內容等比例縮小並留白，不裁切。
2. 閱讀器的 `snapshot()` 回傳當下標題及每頁 `{ id, html }` 的靜態預覽。內容區優先使用 `previewArt`，未提供時使用 `art`；有 `mount` 的頁面仍須提供 `previewArt`。沿用元件縮圖的靜態呈現（例如曲面的熱度圖後備、方塊的四面攤平）與已套用的人工文字／隱藏修改；不帶講稿、註解、畫筆、雷射與即時互動狀態，不執行 `mount` 或 `record`。`iframe`、`object`、`embed`、`video`、`audio` 從匯出副本移除，不自動截取嵌入網頁或影片；作者須在 `previewArt` 提供替代圖片或摘要。
3. `assets/story-reader/export.js` 封裝對話框、依賴載入、圖片內嵌、產檔與取消。閱讀器按既有 script 的位置載入此模組，既有入口不必加 script；截圖在隔離的預覽容器完成，不翻動目前頁面。
4. 使用 html-to-image、jsPDF 及既有 PptxGenJS 的瀏覽器版本。經人同意登記固定版本、MIT 授權與 SHA-256 至 `vendor.json`；套件本體不進 git，點擊下載才載入本機套件，不使用執行期 CDN。
5. `init` 登記閱讀器依賴；`vendor` 對已更新核心但未登記套件的舊工作區補用上游預設，不改寫其清單；`pack` 帶入動態載入的依賴與授權。
6. 支援 HTTP／HTTPS，圖片必須可由瀏覽器讀取；背景圖或圖片讀取失敗即停止匯出。file URL 顯示本機 HTTP 預覽方式，避免靜默缺圖。下載可在斷網的 localhost 使用，套件與圖片須先備妥。
7. 相容新增，不遞增契約版本。CLI `agentdeck export` 的正式 PPT 匯出流程保持獨立。

## 後果

- 讀者不用安裝匯出工具，可直接下載適合分享的靜態檔案；PPTX 裡的文字屬於圖片，無法逐字編輯。
- 檔案大小與產生時間隨頁數增加；逐頁處理，匯出時有進度、取消與錯誤提示。長頁縮小後字可能較小。
- 不保證任意 HTML、外部嵌入或 3D CSS 的截圖效果；互動頁應提供能獨立閱讀的靜態預覽，元件沿用縮圖的靜態呈現。
- 新交付包增加三個匯出套件；首次下載需網路。一般閱讀不載入這些套件。
