# 0041. 多書宿主以 npm 鎖定共用框架，各書原位重建

狀態：已接受

## 背景

簡報樹讓同一本書的章節共用框架（0040）。多本書各自進版控時，核心、預設主題與原廠元件仍會重複。既有工作區也允許作者修改元件副本與主題。

## 決策

多書宿主可用一份 npm 依賴及鎖檔指定 AgentDeck 版本。每本書各自採用此流程，保留既有入口、元件登記與播放路徑。首次接入時逐檔比對鎖版套件，只將可重建的原廠檔案列入該書的 Git 排除清單。書籍來源、人工編輯、自製元件與有差異的副本由宿主追蹤。

重建補齊清單中缺少的檔案，並依現有 vendor manifest 和雜湊還原第三方套件。遇到受管理檔案的人為修改時停止。發行使用版本標籤，宿主鎖定對應的完整 commit 與 npm 封存檔完整性值。

宿主可在接入前查詢檔案歸屬。排除規則使用有起訖標記的區塊，保留區塊外的專案規則。取消追蹤與本機清理共用同一份清單，各自提供預覽；套用前核對鎖版副本、Git 索引及實際生效的排除規則。客製檔案可重新登記為宿主來源。

## 結果

同一宿主只安裝一次，之後每本書可獨立重建與離線打包。讀者取得打包檔即可播放。開發者在乾淨 checkout 首次播放前須安裝和重建；升版時要一起驗證採用該鎖檔的書。操作步驟見[多本書共用一個 AgentDeck 版本](../guides/locked-install.md)。
