# 0006. 閱讀器 fork 自外部專案，獨立演進

- 狀態：已接受
- 日期：2026-09-30

## 背景

`assets/story-reader/` 原本從一個外部的書籍視覺解說專案原樣複製，README 要求以來源為準重新複製。之後在 `reader.js`／`reader.css` 加上了放大播放按鈕（全螢幕加內容放大）。如果再從來源同步，這些修改會被覆蓋。

## 決策

- 本專案的閱讀器正式 fork，獨立演進，不再從外部來源整份覆蓋同步；本專案不記錄或引用該來源的路徑。
- 需要的修正直接在本專案實作。
- 依 [0004](0004-component-template-strategy.md)，閱讀器屬於預設層，LLM 不得擅自修改。

## 後果

- 可以依本專案簡報播放的需求自由調整閱讀器。
- 外部來源的改進不會帶入。README 已改寫為獨立維護說明。
