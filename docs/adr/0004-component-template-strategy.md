# 0004. 元件模板策略：基本模板供參考，新元件先留在主題內

- 狀態：已接受
- 日期：2026-09-30

## 背景

元件由 LLM 實作，不需要事先準備所有元件給 LLM；但新簡報需要一致的起點與外觀。如果 LLM 每次都直接修改共用層，一份簡報的需求就可能讓其他簡報跑版。

## 決策

- **預設層不變**：`assets/`（含 `deck/`、`theme/`、`story-reader/`）與 `templates/` 屬於預設模板。LLM 不得修改，除非人明確要求。
- 預設層只提供基本模板作為參考：
  - `.deck-list`、`.deck-cards`、`.deck-steps`、`.deck-focus`
  - 封面 `.deck-cover`、結尾 `.deck-end`
  - 範本分鏡 `templates/visual-story/`
- **追加的可以刪改**：LLM 為主題新做的元件放在該主題的 `story.css`／`story.js`，class 加主題前綴。LLM 可以自由修改或刪除。
- 同一元件被兩個以上主題重複使用時，經人審核後才升級到 `assets/deck/`。

## 後果

- 共用層穩定，各主題的變動互不影響。
- 不同主題之間可能重複實作類似元件，要靠人定期整理、升級。
- 模板的數量和品質會直接影響 LLM 產出的一致性，模板應保持少而典型。
