# treemap（特殊：d3）

## 用途
階層結構裡各部分的佔比：預算科目、程式碼大小、市場份額、儲存空間。面積即數量，顏色為第一層分組。只有一層、項目少時用 `split` 或 `bars`。

## API
`deck.treemap(key, data, { unit?, caption? })`
- `data`：`{ 名稱: 數字 | { 子項名稱: 數字 | … } }`，可多層；第一層為分組（最多四色循環）。
- `unit`：單位字尾。
- 方塊顯示名稱、數字與佔總量百分比；太小的方塊只顯示名稱，滑過看完整路徑與數字。
- 每個方塊帶 `data-node="<名稱>"`（最底層名稱）。**隨朗讀**：用標註指出方塊，例如 `record: [{ at: 2, box: '[data-key=k] [data-node="研發"]' }]`。
- `caption` 可現場修改；數字與名稱**不開放現場編輯**。
- 產生時就排好版、輸出 HTML，沒有動態內容；未下載套件時退成第一層的清單。
- 需要套件 `d3`：在元件 js 之前引用 `vendor/d3/d3.min.js`。

## 必須保留
- 約 20 個方塊以內；細項合併成「其他」。
- 數值必須是同一總量的組成（可加總）；比較彼此無關的數量用 `bars`。
- 面積難以精確比較；關鍵比例寫進 `caption` 或 `point`。

## 範例
```js
art: deck.treemap('cost', {
  人事: { 研發: 4200, 業務: 1800 },
  營運: { 雲端: 1600, 辦公室: 700 },
  其他: 400,
}, { unit: ' 萬', caption: '人事超過一半。' }),
```
