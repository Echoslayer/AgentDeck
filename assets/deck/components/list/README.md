# list

## 用途
條列重點與層次，對應簡報「標題及內容」的四層清單：● → – → 1. → 1)。

## API
`deck.list(key, items)`
- `items`：字串，或 `{ text, items: [...] }`（巢狀子項目），最多四層，超過會報錯。
- 整份清單是一個可編輯元件（`data-edit`），現場可增刪項目、換行、改粗體。

## 必須保留
- 層級不超過四層；項目太多就拆頁，不要縮小字體。
- 同一層的項目粒度一致。

## 範例
```js
art: deck.list('points', [
  { text: '良率提升', items: ['AOI 初篩', '人工複判'] },
  '工時下降',
]),
```
