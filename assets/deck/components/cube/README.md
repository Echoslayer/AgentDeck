# cube（特殊：CSS 3D 動畫，零依賴）

## 用途
同一主題的四個面向（品質／成本／交期／人力），輪流轉到正面，一次只看一面。適合開場或收尾的「四個面向」總覽。

## API
`deck.cube(key, [{ title, text?, key?, highlight? } ×4], { interval? })`
- 剛好 4 面；`interval` 為每面停留秒數（預設 3）。
- 滑過暫停；編輯模式、縮圖、系統「減少動態」時攤平為四欄，方便改字與逐面隱藏。
- 每面 key 預設 `key-序號`，可單獨隱藏；`title`、`text` 可編輯。

## 必須保留
- 四面是同粒度的並列項目；觀眾需要同時比較時改用 `cards`。
- 自動輪播不配合講者節奏：講者要逐一講解時用 `cards`。
- 每面文字一行標題 + 一句說明，旋轉時才讀得完。
- 隱藏某一面後，旋轉時仍會轉到空白面；要拿掉一面請改 `story.js`。

## 範例
```js
art: deck.cube('impact', [
  { title: '品質', text: '良率 91% → 97%' },
  { title: '成本', text: '每月省 120 萬' },
  { title: '交期', text: '縮短 2 天', highlight: true },
  { title: '人力', text: '複判減半' },
]),
```
