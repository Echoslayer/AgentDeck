# timeline

## 用途
有日期的里程碑與目前進度（專案時程、路線圖）。

## API
`deck.timeline(key, [{ date, label, key?, now? }])`
- 標 `now: true` 的節點為「目前」；之前為已完成，之後為未來。沒有任何 `now` 時全部以中性樣式呈現。
- 節點等距排列，**不依實際日期比例**。
- 每個節點 key 預設為 `key-序號`，可單獨隱藏；日期（`<key>-date`）與說明（`<key>-label`）可在現場修改。
- 窄螢幕自動改為直式。

## 必須保留
- 節點依時間先後排列，約 3–7 個；更多時拆頁或只留關鍵里程碑。
- 間隔差異大且需要看出比例時（例如甘特圖）自製，不要用等距節點暗示等長。
- 只有先後順序、沒有日期時改用 `steps`。

## 範例
```js
art: deck.timeline('plan', [
  { date: '2026 Q1', label: '需求訪談' },
  { date: '2026 Q3', label: '試產導入', now: true },
  { date: '2026 Q4', label: '全線上線' },
]),
```
