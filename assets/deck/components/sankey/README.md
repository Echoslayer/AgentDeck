# sankey（特殊：d3 + d3-sankey）

## 用途
數量從哪裡來、經過哪些階段、最後到哪裡：預算分配、流量去向、轉換漏斗、能源流向。連線寬度即數量。只有一層、2–4 股的拆分用 `split`。

## API
`deck.sankey(key, links, { unit?, caption? })`
- `links`：`[來源, 去處, 數量]` 陣列，數量為正數；節點由名稱自動產生，欄位由連線推導。
- `unit`：單位字尾，例如 `' 人'`、`' 萬'`。
- 顏色：第一欄每個節點一色，後續節點與連線沿用最大來源的顏色。
- `caption` 可現場修改；數字與節點名稱**不開放現場編輯**，要改請改 `story.js`。
- 產生時就排好版、輸出 SVG，沒有動態內容；滑過連線顯示數字。未下載套件時退成逐條清單。
- 需要套件 `d3`：在元件 js 之前依序引用 `vendor/d3/d3.min.js`、`vendor/d3/d3-sankey.min.js`（`agentdeck add` 會依序印出）。

## 必須保留
- 約 3–5 欄、15 個節點以內；更細的分類合併成「其他」。
- 同一節點的流入與流出應相等（或差額另立節點，如「流失」），否則節點高度與觀眾直覺不符。
- 不可有循環（A → B → A）；回流改成另一個節點，如「再次造訪」。

## 範例
```js
art: deck.sankey('budget', [
  ['總預算', '人事', 6900], ['總預算', '營運', 2600], ['總預算', '行銷', 1800],
  ['人事', '研發', 4200], ['人事', '業務', 2700],
], { unit: ' 萬', caption: '年度預算的去向。' }),
```
